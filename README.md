# 簡易水温・室温モニター プログラムリポジトリ
## Simple Water/Room Temperature Monitor (SWRTM) Repository

本リポジトリは、東京工業高等専門学校第58回くぬぎだ祭電子工学科安田研究室企画はんだ付け教室で販売した「簡易水温・室温モニター」のPICマイコンで使用したプログラムや、その製品のサポートを行うリポジトリです。

## 本リポジトリの構成
本リポジトリの構成は以下の通りです

```
Program/
  ├ PIC16F1827/
　│  └ main.c  PICマイコンに書き込んだプログラム
README.md      本リポジトリについて書かれたファイル
```
